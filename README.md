# Photogrammetry Lab

**건국대학교 공간정보 수업의 실습을 위해 만든 사진측량 학습 프로그램 모음입니다.**

사진 두 장에서 공간 좌표와 높이를 구하는 과정, 드론의 위치와 물체 높이에 따른 중심투영의 변화를 직접 조작하며 살펴봅니다.

## 빠르게 시작하기

### 사진측량 실습

**일반 사용자:** 이 저장소의 **Releases**에서 `photogrammetry-v1.0.0-windows-synthetic.zip`을 내려받고 압축을 모두 푼 뒤, `Pack/사진측량실습.exe`를 실행합니다. Python 설치는 필요하지 않습니다. 배포 파일은 저장소 관리자가 Release를 게시한 뒤 제공됩니다.

**소스로 실행:** Python 3.12 이상을 준비하고 `photogrammetry` 폴더에서 다음 명령을 실행합니다. 추가 Python 패키지 없이 실행할 수 있습니다.

```console
python server.py --port 0 --open
```

Windows에서는 `photogrammetry/start.cmd`를 더블클릭할 수도 있습니다. 처음 실행하면 포함된 가상 영상 두 장이 열립니다. GitHub의 **Code → Download ZIP** 또는 자동 생성되는 **Source code.zip**은 소스이며, Windows 실행 파일은 포함하지 않습니다.

### 드론 투영 시뮬레이터

`drone-projection/index.html`을 Chrome 또는 Edge로 엽니다. 프로그램을 실행할 때 인터넷, Python 또는 서버가 필요하지 않습니다.

## 공개 데이터와 수업 자료

이 저장소와 공개 배포 ZIP에는 **실제 드론사진, 실제 촬영 위치, 수업용 외부표정요소(EO), 학생의 측정 기록을 포함하지 않습니다.** 수업 자료는 수업 안에서 별도로 배포합니다.

공개본에 포함된 영상 두 장, `cam.txt`, `eo.txt`, 테스트 자료는 모두 수식으로 만든 **가상 예제**입니다. 실제 자료를 이동하거나 익명화한 것이 아니며 실제 촬영 위치와 관련이 없습니다. 좌표 단위는 m이고, 가상 지면의 높이가 0입니다. 실제 지도상의 EPSG 좌표로 해석하지 않습니다.

실제 사진을 일부만 공개하거나 EO 행을 두 개만 남겨도 촬영 위치가 드러날 수 있으므로, 실제 수업 자료는 공개 예제로 사용하지 않습니다.

## 범위와 해석

사진측량 프로그램은 사용자가 같은 지점을 두 영상에서 직접 관측하는 교육용 도구입니다. 자동 고밀도 점군 생성이나 자동 건물 추출 기능은 포함하지 않습니다. 사진 간 일치도가 좋다는 사실만으로 절대 위치·높이의 정확도가 보장되지는 않습니다.

가상 예제는 기하 계산과 화면 조작을 확인하기 위한 자료입니다. 실제 촬영의 왜곡, 자세각 정의, 주점 오차, 가림, 대응점 판독 난이도까지 재현하지 않습니다.

이 저장소에는 프로그램의 재사용을 허용하는 별도 오픈소스 라이선스를 아직 지정하지 않았습니다. 수업에서 별도로 배포하는 자료의 이용·재배포 조건은 수업 안내를 따릅니다.
