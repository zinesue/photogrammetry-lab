# 드론 중심투영 시뮬레이터

건국대학교 공간정보 수업의 실습을 위해 만든 시뮬레이터입니다. 드론의 위치·고도와 건물 높이를 바꾸며 카메라 영상, 탑뷰와 3D 조감도의 변화를 함께 관찰합니다.

## 실행

`index.html`을 Chrome 또는 Edge로 엽니다. 하나의 HTML 파일에 화면과 동작이 포함되어 있으며 실행할 때 인터넷, Python, 별도 설치가 필요하지 않습니다. 별도의 정적 웹 호스팅에 올려도 사용할 수 있습니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| 방향키 | 드론 수평 이동 |
| W / S | 상승 / 하강 |
| O / P | 두 관측점으로 이동 |
| R | 초기화 |
| 건물 높이 슬라이더 | 가상 건물 높이 변경 |
| 3D 조감도 드래그·휠 | 관찰 시점 회전·확대/축소 |
| 가운데 구분선 드래그 | 좌측 패널 너비 조절 |

촬영 범위·투영광선과 건물 바닥 윤곽 표시를 켜고 끌 수 있습니다. 화면을 한 번 클릭한 후 키보드를 조작하세요.

## 실습 예시

1. 드론을 O에서 P로 이동해 같은 건물의 투영 위치와 보이는 벽면을 비교합니다.
2. 같은 고도에서 건물 높이를 바꾸어 지붕과 바닥 윤곽의 차이를 관찰합니다.
3. 드론의 고도를 높이거나 낮추면서 영상의 축척과 촬영 범위를 비교합니다.

장면과 위치는 모두 가상입니다. 실제 드론사진, 촬영 위치, 수업용 데이터는 사용하지 않습니다.
