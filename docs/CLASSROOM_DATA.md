# 수업 자료 연결 방법

이 프로그램들은 건국대학교 공간정보 수업의 실습을 위해 만들었습니다. 실제 드론사진, 촬영 위치와 수업용 표정요소는 수업 안에서 별도로 배포합니다. 이 문서는 공개 예제를 수업 자료로 바꾸는 방법만 설명하며 실제 위치나 카메라 값을 포함하지 않습니다.

## 소스로 실행하는 경우

공개 저장소의 작업용 복사본에서 수업 자료를 연결합니다. GitHub에 올릴 복사본은 가상 예제 설정으로 유지하세요.

1. `photogrammetry` 안에 `classroom-data` 폴더를 만듭니다.
2. 수업에서 받은 원본 해상도의 왜곡보정 영상과 해당 `cam.txt`, `eo.txt`를 그 폴더에 넣습니다.
3. `photogrammetry/project.json`을 수업에서 제공한 설정으로 바꿉니다. `data_directory`는 `classroom-data`로 지정합니다.
4. `crs`, `height_reference`, `principal_point`, `pose_convention`, `guide_height_range`가 수업 자료에 맞는지 확인합니다. `default_pair`는 빈 배열 `[]`로 두면 사용 가능한 첫 두 장을 선택합니다.
5. 프로그램을 다시 시작합니다. 이전 자료의 결과는 필요하면 교체 전에 JSON으로 내보냅니다.

소스의 폴더 구성은 다음과 같습니다.

```text
photogrammetry/
├─ project.json         수업 자료에 맞게 조정한 설정 (공개 업로드 제외)
├─ server.py
└─ classroom-data/      이 폴더 전체는 비공개
   ├─ cam.txt
   ├─ eo.txt
   └─ 수업에서 받은 영상들
```

좌표계는 수업에서 안내한 실제 자료의 값을 사용합니다. 공개 예제의 `LOCAL_SYNTHETIC_METRES`를 실제 자료에 적용하지 않습니다. 알려지지 않은 주점을 임의로 정확한 값처럼 입력하지 마세요.

## Windows 실행 파일로 실행하는 경우

1. 공개 배포본을 별도의 수업용 폴더에 복사하고 프로그램을 종료합니다.
2. 실행 파일 옆 `데이터` 폴더를 수업용 자료 묶음으로 교체합니다. 가상 PNG와 가상 EO를 실제 자료와 섞지 않습니다.
3. `데이터` 폴더에는 수업 영상, `cam.txt`, `eo.txt`, 수업 설정의 `project.json`이 함께 있어야 합니다.
4. 이 경우 `project.json`의 `data_directory`는 `.`입니다. 다른 설정은 실제 수업 자료에 맞춰야 합니다.
5. 실행 파일을 다시 실행합니다. 수업 자료로 교체한 폴더는 공개 배포 ZIP에 포함하지 않습니다.

프로그램 실행 위치에 따라 별도 실습 기록을 사용합니다. 필요한 기록은 JSON으로 내보내고 새 실행 위치에서 다시 불러오세요.

## 자료 형식

`cam.txt`에는 아래 네 항목을 사용합니다. 수치는 예제에서 복사하지 말고 수업 자료의 값을 사용합니다.

| 항목 | 의미 |
| --- | --- |
| `focal_length` | 초점거리, mm |
| `pixel_size` | 픽셀 크기, mm |
| `image_size_x` | 영상 너비, px |
| `image_size_y` | 영상 높이, px |

`eo.txt`는 다음 머리글을 사용하는 CSV 형식입니다.

```csv
PhotoID,X,Y,Z,Omega,Phi,Kappa
```

PhotoID는 영상 확장자를 제외한 파일명과 일치해야 합니다. X, Y, Z의 단위는 m이고 프로그램은 X=E, Y=N, Z=H로 해석합니다. Omega, Phi, Kappa의 단위는 degree이며 지원하는 자세각 정의는 `camera_to_world_RxRyRz`입니다. 다른 프로그램에서 만든 EO가 같은 이름의 열을 사용해도 회전 정의가 다를 수 있습니다.

사진을 줄이거나 잘라내면 영상 크기·픽셀 크기·주점 등의 관계가 달라질 수 있으므로, 수업에서 제공한 카메라 정보와 맞는 영상을 사용합니다.

## 공개본을 유지하는 방법

- 공개 저장소에는 가상 예제만 포함합니다. 실제 사진 두 장이나 EO 두 행만 남기는 방법도 촬영 위치 비공개 요구를 충족하지 않습니다.
- `.gitignore`는 지정된 비공개 폴더, 사진, EO와 측정 기록을 제외하도록 설정되어 있습니다. GitHub 웹에서 직접 파일을 선택해 올릴 때에는 `.gitignore`가 파일 선택을 막아주지 않으므로 공개용 폴더만 업로드합니다.
- 이미 추적 중인 `project.json`의 수정 내용은 `.gitignore`로 숨길 수 없습니다. 공개 업로드 전 `examples/synthetic/project.json`을 `photogrammetry/project.json`으로 복사해 가상 예제 설정으로 복구합니다.
- 측정 기록, 백업, 내보낸 CSV/DXF/JSON, 화면 캡처에도 위치가 들어갈 수 있으므로 수업 자료와 함께 비공개로 보관합니다.
- 공개 패키징 도구는 현재 수업 설정을 사용하지 않고 `examples/synthetic`에서 가상 자료만 선택합니다. 이 예제 폴더 자체는 수업 자료로 교체하지 않습니다.
