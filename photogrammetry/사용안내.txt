사진측량 실습 프로그램 — 공개 가상 예제 버전
건국대학교 공간정보 수업의 실습을 위해 만든 프로그램입니다.

1. 시작하기
  Windows 실행본: 압축을 모두 풀고 Pack 안의 사진측량실습.exe를 실행합니다.
  실행 파일과 데이터 폴더를 함께 보관합니다. Python 설치는 필요 없습니다.
  소스: Python 3.12 이상을 설치하고 photogrammetry 폴더에서 실행합니다.
    python server.py --port 0 --open
  Windows에서는 start.cmd를 더블클릭할 수도 있습니다.
  인터넷 연결 없이 이 컴퓨터의 브라우저에서 실행됩니다.

2. 공개 예제의 의미
  포함된 두 영상과 cam.txt, eo.txt는 모두 수식으로 만든 가상 자료입니다.
  실제 드론사진, 촬영 위치 또는 수업용 관측 기록을 포함하지 않습니다.
  좌표는 가상 로컬 좌표(m), 높이는 가상 지면 0 m를 기준으로 합니다.
  실제 지도 좌표로 해석하지 마세요.
  G1, G2, G3 표식은 높이 0 m, R1~R4 표식은 높이 20 m입니다.
  파란 지붕의 다른 가상 건물은 높이 35 m입니다.

3. 대응점으로 측정
  A에 SYNTH_A, B에 SYNTH_B 영상을 선택합니다.
  A에서 G1 표식의 중심을 클릭하고 B에서 같은 G1 중심을 클릭합니다.
  좌표와 사진 간 일치도를 살펴본 뒤 Enter 또는 점 저장을 누릅니다.
  G2, G3도 저장하고 지형 만들기를 누르면 지면 삼각망이 만들어집니다.
  건물 그리기에서 R1, R2, R3, R4를 차례로 저장하고 면을 닫습니다.
  지면 점을 기준 지면으로 선택해 지붕과의 높이 차이를 확인합니다.

4. 가이드와 높이 유지
  점 맞추기에서 가이드 커서 조절을 고릅니다.
  A를 클릭한 뒤 B에서 Shift+휠 또는 Shift+드래그로 높이를 조절합니다.
  두 사진에서 같은 지점이 맞으면 Enter로 저장합니다.
  높이 유지하며 그리기는 첫 모서리의 높이를 맞춘 후 A의 다음 모서리를
  선택해 같은 높이의 꼭짓점을 추가합니다. 높이가 달라지면 다시 맞춥니다.
  이 두 방식의 높이는 사용자가 선택한 제약이므로 독립 재투영오차가 없습니다.

5. 화면 조작
  사진: 휠 확대·축소, 일반 드래그 이동, F 또는 전체 보기로 맞춤.
  사진 목록: 좌클릭은 A, 우클릭은 B 선택.
  3D: 드래그 회전, Shift+드래그 또는 휠 버튼 드래그 이동, 휠 확대·축소.
  전체 보기로 이동과 확대를 초기화하고, 입체/위에서 보기로 방향을 바꿉니다.
  크게 버튼으로 3D를 확대하고 Esc로 돌아옵니다.
  지형·벽면·시선·등고선·높이·점 번호 표시를 각각 조절할 수 있습니다.
  Enter: 점 저장. Esc: 선택 취소. Ctrl+Z: 마지막 작업 되돌리기.

6. 지형과 건물 높이
  지면 점 세 개 이상이 필요하며 한 직선에만 있으면 면을 만들 수 없습니다.
  지형은 지면 점으로 둘러싸인 범위에서 선형 보간하며 바깥으로 확장하지 않습니다.
  점을 바꾼 뒤 지형 갱신을 눌러 반영합니다.
  건물 벽면은 미리보기용 수직 연장 모형이며 실제 벽을 복원한 결과가 아닙니다.
  건물과 겹치는 지형의 최저 높이를 공통 바닥으로 사용합니다.
  지형이 없거나 겹치지 않으면 건물별 또는 공통 기준 지면을 사용합니다.
  지붕 높이, 벽면 길이, 바로 아래 지형과의 높이 차이는 서로 다른 값입니다.

7. 저장과 내보내기
  소스 실행: photogrammetry/measurements.json에 자동 저장합니다.
  Windows 실행본: 사용자 저장소의 DronePhotogrammetryPractice 아래에 저장합니다.
  실행 위치가 달라지면 별도 저장소를 사용합니다.
  CSV는 E,N,H와 관측값, DXF는 실제 Z를 가진 점과 3D 외곽선입니다.
  JSON은 작업 기록을 옮기거나 다시 불러올 때 사용합니다.
  새 실습 시작, 자료 교체 및 이전 형식 변환 후에도 백업이 남을 수 있습니다.
  측정 기록·백업·내보낸 결과는 수업 자료와 함께 비공개로 보관합니다.

8. 실제 수업 자료
  실제 사진과 촬영 위치는 수업에서 별도로 배포합니다.
  소스에서는 classroom-data 폴더를 만들고 수업 자료와 연결 설정을 적용합니다.
  Windows 실행본에서는 데이터 폴더 전체를 수업용 자료 묶음으로 교체합니다.
  사진뿐 아니라 cam.txt, eo.txt, project.json의 좌표계·높이 기준·주점도
  수업 자료에 맞아야 합니다. 가상 예제 설정을 그대로 사용하지 마세요.
  자세한 절차는 저장소 docs/CLASSROOM_DATA.md를 참고합니다.

9. 결과 해석
  이 프로그램은 교육용이며 절대 위치·높이 정확도를 보증하지 않습니다.
  서로 다른 지점도 탐색선 위에 있으면 작은 오차가 나올 수 있습니다.
  항상 같은 지점인지 직접 확인하세요. 가상 자료의 성공이 실제 촬영 자료의
  카메라 보정, 자세각 또는 위치 정확도 검증을 대신하지 않습니다.
