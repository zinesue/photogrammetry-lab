# 공개 가상 예제

이 폴더는 실제 드론사진이나 실제 촬영 위치를 사용하지 않고 만든 자료입니다. `tools/generate_synthetic.py`가 수식으로 가상의 지면·건물·카메라를 투영해 두 PNG 영상을 생성합니다. 원본 사진을 자르거나 좌표만 이동한 자료가 아닙니다.

- 영상: `SYNTH_A.PNG`, `SYNTH_B.PNG` / 1600×1200 px
- 가상 카메라 위치: A=(-15, 0, 160), B=(15, 0, 160) m
- 가상 OPK: 두 카메라 모두 (0, 0, 0)°
- 초점거리: 12 mm / 픽셀 크기: 0.01 mm / 주점: (800, 600) px
- 좌표계: `LOCAL_SYNTHETIC_METRES` / 가상 지면 H=0 m
- PNG에는 EXIF 또는 GPS 메타데이터가 없습니다.

`cam.txt`, `eo.txt`도 모두 가상 값입니다. `project.json`은 소스 폴더의 설정을 가상 예제로 복구할 때 사용할 수 있습니다. Windows 패키징 도구는 배포용 데이터 경로에 맞춰 이 설정의 `data_directory`를 `.`으로 바꿉니다.

## 관측할 표식

두 영상에서 같은 이름의 붉은 십자 중심을 선택합니다.

| 표식 | E (m) | N (m) | H (m) |
| --- | ---: | ---: | ---: |
| G1 | -40 | -30 | 0 |
| G2 | 35 | -30 | 0 |
| G3 | -40 | 35 | 0 |
| R1 | -22 | -16 | 20 |
| R2 | 18 | -16 | 20 |
| R3 | 18 | 16 | 20 |
| R4 | -22 | 16 | 20 |

G1~G3은 지면 측정과 삼각망 실습, R1~R4는 지붕 외곽선 도화에 사용합니다. 다른 파란 지붕의 높이는 35 m입니다. 정확한 영상 좌표는 `checkpoints.json`에 있습니다.

기준값은 이상적인 핀홀 카메라 수식으로 계산했습니다. 사람이 표식 중심을 클릭할 때에는 픽셀 단위의 오차가 생깁니다. 가상 예제는 실제 촬영의 질감, 가림, 왜곡, 자세 오차를 재현하지 않습니다.
