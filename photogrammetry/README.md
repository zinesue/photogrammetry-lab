# 사진측량 실습 프로그램

건국대학교 공간정보 수업의 실습을 위해 만든 프로그램입니다. 겹치는 두 영상에서 같은 지점을 선택하여 공간 좌표와 높이를 계산하고, 건물 외곽선과 지형을 그립니다.

## 실행

- Windows 배포본: Release ZIP을 모두 풀고 `Pack/사진측량실습.exe`를 실행합니다. Windows 10/11 64비트용이며 Python 설치가 필요하지 않습니다.
- 소스: Python 3.12 이상에서 이 폴더를 작업 폴더로 열고 `python server.py --port 0 --open`을 실행합니다.
- Windows 소스: Python을 설치한 뒤 `start.cmd`를 실행할 수도 있습니다. 이 폴더의 `.venv`가 있으면 우선 사용합니다.
- 실행 중 인터넷 연결은 필요하지 않습니다. 서버는 이 컴퓨터의 `127.0.0.1`에만 연결됩니다.
- 처음에는 `examples/synthetic`의 가상 영상 두 장을 사용합니다.

`web/index.html`만 직접 열면 측량 계산과 저장 기능을 사용할 수 없습니다. 이 프로그램은 로컬 Python 서버 또는 패키징 실행 파일과 함께 실행합니다.

## 첫 실습: 가상 건물의 높이 확인

1. A 영상 `SYNTH_A.PNG`, B 영상 `SYNTH_B.PNG`를 선택합니다.
2. 지면 높이 찍기에서 두 영상의 **G1** 표식 중심을 각각 선택하고 점을 저장합니다. 예상 높이는 **0 m**입니다.
3. G2와 G3도 같은 방식으로 관측합니다. 지면 점 세 개를 저장하면 지형을 만들 수 있습니다.
4. 건물 그리기에서 **R1 → R2 → R3 → R4**의 표식 중심을 대응시켜 저장하고 면을 닫습니다. 예상 지붕 높이는 **20 m**입니다.
5. 가이드 커서 방식에서는 A의 R1을 선택한 뒤 B에서 Shift+휠로 높이를 조절합니다. **20 m**에서 커서가 같은 표식과 맞는지 살펴봅니다.

각 표식의 정확한 좌표와 영상 좌표는 [예제 설명](examples/synthetic/README.md) 및 `examples/synthetic/checkpoints.json`에 있습니다. 사람이 클릭한 결과에는 픽셀 선택 오차가 생길 수 있습니다.

## 주요 기능

- 두 사진의 대응점을 이용한 공간 전방교회와 재투영오차 확인
- 가이드 커서와 높이 유지 방식의 건물 외곽선 도화
- 지면 점의 삼각망, 지형에 맞춘 건물 벽면 미리보기와 등고선
- 회전·이동·확대 가능한 3D 보기
- CSV, DXF, JSON 내보내기 및 실습 기록 다시 불러오기
- 작업 되돌리기, 자동 저장, 사진·카메라 자료 교체 감지

자세한 조작은 [사용안내.txt](사용안내.txt)를 참고하세요.

## 좌표와 카메라 해석

공개 예제의 좌표계 표시는 `LOCAL_SYNTHETIC_METRES`입니다. E는 오른쪽, N은 위쪽, H는 위쪽 높이를 뜻하는 가상 로컬 축이며 실제 지도 위치에 연결되지 않습니다.

영상 좌표는 좌상단에서 시작하고 u는 오른쪽, v는 아래쪽으로 증가합니다. 예제의 주점은 `(800, 600)`, 초점거리는 12 mm, 픽셀 크기는 0.01 mm, 영상 크기는 1600×1200 px입니다. 예제 카메라는 높이 160 m에서 아래를 보며 기선 길이는 30 m입니다.

내부 계산의 카메라 광축은 -z, OPK는 degree이며 camera-to-world `Rx(omega) × Ry(phi) × Rz(kappa)`로 해석합니다. 실제 자료는 왜곡보정된 영상과 그 영상에 맞는 내부표정요소 및 자세각 정의를 사용해야 합니다.

## 수업 자료 사용과 저장

수업에서 제공받은 자료는 공개 저장소와 분리해 보관하세요. 연결 절차는 [수업 자료 연결 방법](../docs/CLASSROOM_DATA.md)에 있습니다. 가상 예제의 좌표계·높이 기준을 실제 수업 자료에 그대로 적용하지 않습니다.

소스 실행의 실습 기록은 이 폴더의 `measurements.json`에 저장됩니다. Windows 배포본은 `%LOCALAPPDATA%\DronePhotogrammetryPractice` 아래의 실행 위치별 저장소를 사용합니다. 기록을 옮기려면 JSON으로 내보낸 후 불러옵니다. 기록과 백업은 공개 업로드 대상이 아닙니다.

## 검증과 실행 파일 만들기

[개발·배포 안내](../docs/DEVELOPMENT.md)에 테스트 실행, 가상 데이터 재생성, Windows 패키징 방법을 정리했습니다. 공개 패키징 도구는 수업 자료 대신 가상 예제만 포함하도록 구성되어 있습니다.
